The font names Arial, Times New Roman, Courier New, Calibri, Cambria, Georgia, Verdana and Comic Sans MS are only used to pick the matching installed system font. Those fonts are not included; when they are missing, Layr uses the open stand-ins listed above.

**Dictation model:** Layr does not include a speech model. Only when you set up dictation and click *Download and install*, Layr downloads [NVIDIA Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) (© NVIDIA, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)) in the int8 ONNX version published by the sherpa-onnx project (`sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2` from its GitHub release *asr-models*, exported to ONNX and quantized to int8 by the sherpa-onnx project). The archive and every file in it are checked against fixed SHA-256 checksums. The model is stored in Layr's settings folder and can be removed there at any time. Details: [`licenses/Parakeet-TDT-0.6B-v3-CC-BY-4.0.txt`](licenses/Parakeet-TDT-0.6B-v3-CC-BY-4.0.txt).

**German spell checking:** Layr does not include a German dictionary. It uses the Hunspell dictionary that is already installed on your system (on Ubuntu e.g. the package `hunspell-de-de`) or, on Windows, the one from an installed LibreOffice. If none is found, Layr can download it once, only when you click *Download German dictionary*: the file is the [igerman98](https://www.j3e.de/ispell/igerman98/) dictionary by Björn Jacke (GNU GPL 2 or 3), taken from the public npm package [`dictionary-de` 3.0.0](https://www.npmjs.com/package/dictionary-de) and checked against a fixed SHA-512 checksum. It is stored in Layr's settings folder together with its license text.
